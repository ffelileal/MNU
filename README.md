# 🌐 Modelo Naciones Unidas Interactivo

Una plataforma digital pensada para delegados, organizadores y observadores del Modelo de Naciones Unidas.
Accedé fácilmente a información de tópicos, comités, países, cronograma, resoluciones y más, todo en un entorno moderno, responsivo y gratuito.

> 🕊️ Proyecto educativo y de difusión del MUN + desarrollo web.

---

## 🔎 Vista previa online

➡️ [https://modelo-naciones-unidas.vercel.app](https://modelo-naciones-unidas.vercel.app)

---

## 🧠 Funcionalidades

* 🧾 Navegación por comités y temas asignados
* 🌍 Buscador de países, bloques y delegaciones
* 📝 Sección de resoluciones y documentos oficiales
* ⏰ Cronograma del evento actualizado
* 🧑‍⚖️ Panel de autoridades, con biografía y contacto
* 📖 Glosario de términos diplomáticos
* 🗺️ Mapa interactivo de distribución de países
* 🌓 Modo oscuro / claro
* 📱 Totalmente responsiva (funciona en móvil, tablet y PC)

---

## 🛠️ Tecnologías usadas

* ⚛️ React
* 💅 Tailwind CSS para el diseño moderno y adaptable
* 📄 Markdown + JSON para el manejo de contenidos
* 📦 Vite
* 🎨 Framer Motion para animaciones suaves
* 🗺️ Leaflet.js para el mapa (opcional)
* ☁️ Hosting en [Vercel](https://vercel.com)
